---
title: Encrypted secrets
description: Store environment secrets as encrypted project files without committing plaintext values.
---

dygo stores project secrets in age-encrypted environment files. The encrypted files can live in source control. The private master key stays outside the repository.

## Initialize secret storage

```sh title="Terminal"
dygo secret init
```

This creates the local private key and encrypted environment files.

## Edit secrets

```sh title="Terminal"
dygo secret edit
```

The command decrypts the development file into a temporary editor buffer, validates the result, and encrypts it again.

Select another environment explicitly:

```sh title="Terminal"
dygo secret edit --env production
```

## Read one value

```sh title="Terminal"
dygo secret get DATABASE_URL
```

`secret get` writes the raw value to standard output for scripts. Keep logs and command traces from capturing that output.

## Validate references

```sh title="Terminal"
dygo secret validate
dygo secret validate --env production
```

## Rotate the key

Preview and then rotate:

```sh title="Terminal"
dygo secret rotate-key --dry-run
dygo secret rotate-key
```

Store the new private key through your deployment secret channel. Do not commit `.dygo/secrets/master.key`.

External secret providers are not part of the current runtime.
